# 🎵 陶笛回家練習（Firebase 版）

學生回家用麥克風練習 → 過關記一次 → 累計積分和等級；老師後台派每週任務、看練習狀況、調整判定寬鬆度。
做法和「陶笛失落地圖」同一套：GitHub Pages 放網頁，資料放**一個全新、獨立的 Firebase 專案**（和失落地圖不共用）。

## 檔案（全部放在同一個 GitHub repo 的根目錄）

| 檔案 | 用途 |
|---|---|
| `index.html` | 學生頁（登入、任務、麥克風練習） |
| `admin.html` | 老師後台 |
| `core.js` | 共用：收音判定、音符寫法、積分／等級計算 |
| `student-auth.js` | 學生登入（姓名＋分部＋自設密碼） |
| `student-data.js` / `admin-data.js` | 學生／老師讀寫 Firestore |
| `firebase-config.js` | **你要填的**：新 Firebase 專案的設定 |
| `firestore.rules` | **你要貼到 Firebase 的**安全規則 |
| `test/` | 自動測試（不用上傳到網站） |

## 設定步驟（約 15 分鐘，只做一次）

☐ 1. 開 [Firebase 控制台](https://console.firebase.google.com) → **新增專案**（取新名字，例如 `ocarina-practice`；不要用失落地圖那個）
☐ 2. **建立 → Authentication → 開始使用 → 登入方式 → 電子郵件／密碼 → 啟用**（只開第一個，不用開「電子郵件連結」）
☐ 3. **Authentication → 使用者 → 新增使用者**：Email 填 `firebase-config.js` 裡的 `adminEmail`（預設 `a0929870116@gmail.com`），密碼自己設（這就是老師後台密碼）
☐ 4. **Authentication → 設定 → 授權網域 → 新增網域**：填 `你的帳號.github.io`
☐ 5. **建立 → Firestore Database → 建立資料庫**（位置選 `asia-east1` 台灣；模式選「正式版」）
☐ 6. Firestore → **規則** → 把 `firestore.rules` 整份貼上 → **發佈**
   （檔案裡的 `a0929870116@gmail.com` 若你換了老師 Email，要兩個地方一起改：`firestore.rules` 和 `firebase-config.js`）
☐ 7. 專案設定（齒輪）→ 一般 → 你的應用程式 → **新增網頁應用程式** → 複製 SDK 設定 → 貼進 `firebase-config.js` 的 `config`
☐ 8. 把整包上傳到 GitHub repo → Settings → Pages → 啟用
☐ 9. 打開 `admin.html` 登入 → **⚙️ 放寬設定**按一次儲存（建立設定檔）→ **📋 每週任務**派第一個任務
☐ 10. 學生打開 `index.html` →「第一次來」→ 姓名、分部、自訂密碼 → 勾家長確認 → 開始練習

## 學生怎麼登入
- **姓名＋分部（自己填的分校名稱）＋自己設的密碼**。不用 Email、不用手機號碼。
- 「分部」是自填的分校名，打錯字會變成另一個人。老師後台 **✏️ 合併／改分部名稱** 可以把打錯的併回來（學生用新舊名稱都登入得進去）。
- **忘記密碼**：老師後台 → 學生總覽 → 管理 → 重設密碼；學生選「第一次來」，用**同樣的姓名和分部**設新密碼，積分、進度都保留。

## 老師後台
- **學生總覽**：等級、積分、本週次數、累計、最近練習；篩分部、只看本週沒練的；加減積分、重設密碼、刪除。
- **每週任務**：名稱、指派給「全部」或某個分部、需過關次數、完成得幾分、起訖日；收音音符（留空＝自由吹奏）；原速 BPM（填了＝跟著節拍吹並開放三個速度階段）。可「複製上週任務」。
  - 音符寫法：簡譜 `1 2 3 4 5 6 7`；高音加單引號 `1' 2'`；休止 `0`；拍數寫冒號後 `5:2`＝吹 2 拍。
- **放寬設定**：音準容許（音分）、每個音要吹多久、可以漏掉幾 %、節奏可早晚幾拍、每個音要吹到的比例、自由吹奏秒數、**三個速度階段（預設 100／90／80）**、節拍聲；有「最寬鬆／預設／較嚴格」一鍵套用。改完學生下次打開頁面就套用。
- **練習紀錄**：最近 200 筆。

## 積分與等級怎麼算
- 不另外存，每次由「任務＋練習紀錄＋老師加減分」算出：**任務過關次數達標 → 得該任務的積分**；老師手動加減；不會低於 0。
- 等級：陶笛蛋 0 → 小音符 20 → 陶笛學徒 50 → 星星樂手 100 → 音符冒險家 180 → 陶笛勇者 300 → 陶笛大師 500。
- 每人每項任務每天最多記 5 次。
- ⚠️ 刪除任務 → 該任務的積分也會消失（練習紀錄不會刪）。

## 已知限制（請知道）
1. **麥克風判定在學生手機上進行**，紀錄由學生的瀏覽器寫入。懂技術的人可以不吹就偽造紀錄（Firestore 規則只能限制格式、次數、日期，擋不了這個）。對國小到成人的課後練習，這是可接受的取捨；若要防作弊，需要伺服器端驗證（要升級 Blaze 方案並用 Cloud Functions）。
3. **更新程式後要重新發佈規則**：`firestore.rules` 有新增 `plays`（每次有效練習）。把整份 `firestore.rules` 貼到 Firebase → Firestore → 規則 → 發佈。沒發佈的話，學生頁照常能用，但「累計練習」只會算全對那幾次。
2. **`firestore.rules` 沒有在真的 Firebase 上跑過**——我只能用等價的假資料庫測試用戶端流程（50 項檢查）。上線第一天請自己走一遍：註冊、過關、老師看得到、重設密碼、改分部。若發佈規則時 Firebase 報語法錯誤，把錯誤訊息貼給我。
3. 真的手機、真的陶笛、真的 Firebase 專案都沒測過；判定參數（預設很寬）請用一兩位學生實測後再調。
4. 學生刪除後，他在 Firebase Authentication 的帳號仍留著（網頁端沒有權限刪），不影響使用，之後同名可以重新註冊。
